# Task: Write tests for local hook system in `test_whats_next.py`

## Description

Add tests to `tests/test_whats_next.py` (and/or a new `tests/test_whats_next_hooks.py`)
covering all aspects of the CIP-0017 local hook system. Use `tmp_path` fixtures to create
transient local modules so tests are fully self-contained and leave no side effects.

## Acceptance Criteria

### `_load_local_module()` tests
- [ ] Returns `None` when `.vibesafe/whats_next_local.py` does not exist
- [ ] Returns a module object when the file exists and is valid Python
- [ ] Prints a warning and returns `None` when the file contains a syntax/import error
- [ ] Loaded module has expected attributes when defined in the stub

### `get_local_next_steps()` integration tests
- [ ] Plain `str` items appear after VibeSafe suggestions
- [ ] `("high", str)` items appear before VibeSafe suggestions
- [ ] `("low", str)` items appear after VibeSafe suggestions
- [ ] Mixed list (high + low + plain) produces correct ordering
- [ ] Exception inside `get_local_next_steps()` is caught; warning printed; rest of output unaffected
- [ ] When `get_local_next_steps` is absent from module, no error is raised

### `get_local_sections()` integration tests
- [ ] 2-tuple `(title, lines)` section appears in the `"after"` position
- [ ] 3-tuple `(title, lines, "before")` section appears before built-in sections
- [ ] 3-tuple `(title, lines, "after")` section appears after built-in sections
- [ ] Exception inside `get_local_sections()` is caught; warning printed; rest of output unaffected
- [ ] When `get_local_sections` is absent from module, no error is raised

### Baseline / regression tests
- [ ] When no local module exists, output is byte-for-byte identical to the pre-CIP-0017 behaviour
- [ ] Context dict passed to hooks contains all five expected keys

### Integration test
- [ ] End-to-end: run `whats-next` (or call `main()`) against a fixture project directory
  containing a `.vibesafe/whats_next_local.py` and verify sections and steps appear in
  the expected positions in captured stdout

## Implementation Notes

Use `pytest`'s `tmp_path` fixture and `monkeypatch` (or `importlib` directly) to create
transient modules. Write the module source to a temp file and pass its path to
`_load_local_module()`.

```python
def test_load_local_module_missing(tmp_path):
    mod = _load_local_module(str(tmp_path / "nonexistent.py"))
    assert mod is None

def test_load_local_module_valid(tmp_path):
    p = tmp_path / "whats_next_local.py"
    p.write_text("def get_local_next_steps(ctx): return ['hello']")
    mod = _load_local_module(str(p))
    assert mod is not None
    assert hasattr(mod, "get_local_next_steps")

def test_load_local_module_broken(tmp_path, capsys):
    p = tmp_path / "whats_next_local.py"
    p.write_text("syntax error !!!")
    mod = _load_local_module(str(p))
    assert mod is None
    assert "Warning" in capsys.readouterr().out
```

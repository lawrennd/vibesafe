# Task: Write tests for `check_cip_backlog_coverage()` — 7 scenarios

## Description

Add test cases to `tests/test_validate_vibesafe_structure.py` covering the
seven scenarios defined in CIP-0019.

Use the existing `tmp_path`-style fixture pattern to create minimal CIP and
backlog YAML files in a temporary directory tree.

## Acceptance Criteria

All 7 test scenarios pass:

- [ ] CIP `In Progress`, no backlog tasks → warning emitted
- [ ] CIP `Accepted`, no backlog tasks → warning emitted
- [ ] CIP `Proposed`, no backlog tasks → **no** warning (not yet active)
- [ ] CIP `Implemented`, no backlog tasks → **no** warning (done)
- [ ] CIP `Closed`, no backlog tasks → **no** warning (done)
- [ ] CIP `In Progress` with a matching backlog task (`related_cips` contains the CIP id) → **no** warning
- [ ] `--no-cip-backlog-check` flag suppresses all warnings from this check
- [ ] (Bonus) `--strict` with an uncovered CIP causes non-zero exit code

## Implementation Notes

Look at the existing `TestGovernanceDrift` test class in the file for the
pattern of creating temporary fixture trees and asserting on
`result.warnings` / `result.errors`.
